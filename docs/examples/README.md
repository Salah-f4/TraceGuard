# Accessible synthetic examples

These files are generated by tools/generate_examples.py with networking blocked.
They contain fabricated evidence and AI selections, not live provider results.
The example hashes identify documented harmless strings, not malware samples.

- offline.txt: complete text counterpart to images/offline.svg; documentation IP
  and example.com URL with unknown evidence, no external calls.
- mocked-ai.txt: complete text counterpart to images/mocked-ai.svg; a harmless
  SHA-256 syntax candidate with synthetic adverse evidence and validated local
  claim selection. Token usage is fabricated, not a performance measurement.
- report-excerpt.json: annotated excerpt, not the complete JSON report schema.

SVGs are Rich-rendered terminal excerpts, not whole reports. Offline shows the first
25 lines; mocked AI shows the introduction and AI section, with an omission marker.
No screenshot contains account UI, real source files or personal identifiers.
